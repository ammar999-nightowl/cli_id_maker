# cli_id_maker
A cli id maker , i am building it as a personal project. 
its a cli id maker that requirs you
to input **info** . its pretty basic and 
fun

**how to build**
thats pretty simple, just use clang
# Clean old build artifacts, create a new build folder, and enter it
rm -rf build && mkdir build && cd build

# Configure, build with Clang, and run
cmake -DCMAKE_CXX_COMPILER=clang++ .. && make && ./id_card

make
./id_card
